隐私政策

本政策说明湘小婉经营助手如何处理餐厅外卖经营数据、导入文件、导出报表和本地应用数据。

最后更新：2026年5月13日

简短说明：湘小婉经营助手用于在 Mac 上整理餐厅外卖数据、生成周报/月报和导出经营报表。应用不要求创建账号，不主动收集个人信息，不出售数据，也不将餐厅经营数据上传到我们的服务器。

我们处理的数据

当您使用应用时，您可能会导入外卖平台或门店经营相关文件。这些文件可能包含营业额、订单量、客单价、平台、门店、日期、活动费用、退款、配送、评价或其他经营指标。

这些数据用于在应用内计算图表、周报、月报、平台对比、门店对比和导出报告。

数据存储位置

  • 导入的数据主要在您的设备本地处理。
  • 您导出的 Excel 或 HTML 报告会保存到您自己选择的位置。
  • 如果应用保存偏好设置或临时数据，它们会保存在 macOS 为应用提供的本地存储区域。

我们不会做的事情

  • 不会出售、出租或交易您的餐厅经营数据。
  • 不会要求您注册账号才能分析本地数据。
  • 不会主动上传您的导入文件或导出报告到我们的服务器。
  • 不会使用您的经营数据做广告投放画像。

第三方服务

如果未来版本接入云同步、账号登录、支付、错误日志、分析服务或外部平台接口，我们会在应用内或本页面更新说明，并根据适用规则请求必要权限。

导出报告

应用可以导出包含经营数据、指标说明和图表的 HTML 或 Excel 文件。导出后，这些文件由您自行管理。如果您将报告发送给他人或上传到第三方平台，相关平台的隐私政策将适用于这些文件。

数据删除

您可以删除导入源文件、导出的报告文件，或在应用内清理已导入的数据。如果您删除应用，macOS 通常会移除应用相关数据，但由您手动保存到其他位置的文件不会自动删除。
