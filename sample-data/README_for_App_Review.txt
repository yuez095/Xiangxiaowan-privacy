Xiangxiaowan App Review Test Data

These files are synthetic sample data for App Review testing.
All store names and numeric values are generated examples and do not contain real restaurant business data.

Files included:
- 美团_外卖_sample.csv
- 美团_拼好饭_sample.csv
- 饿了么_外卖_sample.xlsx
- 饿了么_爆品团_sample.xlsx
- 京东_外卖_sample.xlsx

How to test:
1. Launch Xiangxiaowan.
2. Open the data import section.
3. Import one or more files from this folder.
4. The app can infer platform/channel from the filenames.
5. After import, review the dashboard, weekly report, trend charts, monthly report, store ranking, and metric glossary.
6. Use the download/export button to generate the report/data output.

No login, account, payment, subscription, external service, or network setup is required.
All processing is local on the Mac.
